# 涡流阵列采集系统 v3 — 上位机（毫伏协议）

适配 STM32 固件 **v3 毫伏协议** 的上位机
（固件工程：[..\v2](../v2)，权威协议文档：[..\v2\PROTOCOL.md](../v2/PROTOCOL.md)）。
本项目位于 [shangweiji/](.)，不修改原 [面包板验证电路/software/上位机](../面包板验证电路/software/上位机) 任何内容。

## 1. 概述

`shangweiji` 是一个用 **Python + PyQt5 + pyqtgraph** 写的桌面应用，运行在
Windows 上，通过 USB CDC 虚拟串口接收 STM32 固件发出的实时
**16 通道毫伏扫描帧**（D 帧）和 **初始化心跳**（E 帧），
然后在 4×4 热力图、选中通道信息面板和实时曲线上展示。

**v3 协议要点**（详见 [PROTOCOL.md](PROTOCOL.md)）：

- D 帧固定 **22 字段**：`D,<scan>,<status>,<valid_mask>,<i2c_err>,mV,<S1_mV>..<S16_mV>`
- 字段 [5] 是字面量 **`mV`** 单位标记；16 个测量值**固定 3 位小数**
- 每个值是 **0.125 mV**（125 µV = 1 LSB）的整数倍，范围 [-4096.000, 4095.875]
- **mV 是端到端权威单位**：解析、滤波、基线、Δ、热力图、曲线、CSV、
  回放全部 mV；不做 mV → raw count 反算
- 固件**不接收任何命令**；上位机只读
- 实机（COM9）约 3.5 fps；首通道实样 424.625 mV

**实验流程**：先移除钢板做**无钢板基线标定**（基线固定，不自动
追踪），再放入钢板观察**衰减量 = 基线 − 当前检波电压**与
**检波电压下降比例**（详见第 7 节）。信号高于基线时如实显示负值，
绝不取绝对值、截零或强制翻转。

## 2. 硬件数据链路

```
AD9834 信号源
  → OPA541 功放
  → 大激励线圈
  → 金属目标产生涡流
  → 16 个接收线圈
  → ADG706 1-of-16 分时选通 (S1..S16 → AIN0)
  → AD8362 RMS/功率检波（对数直流输出）
  → 1/2 分压 (10k+10k) + RC 低通
  → ADS1115 AIN0 (16-bit signed, ±4.096V, 860 SPS, 连续转换)
  → STM32 USB CDC 虚拟串口（发送 mV 文本，不发 raw count）
  → Windows 上位机
```

### 3.4 覆盖分析

主窗口顶部点击 **覆盖分析**。连接串口、TCP，或打开现有 mV CSV 进行回放，即可使用当前帧。分析使用 16 个有效、未到量程边界的 ADC 原始毫伏值。

1. 铁板远离大激励线圈时，点击 **采集空场**，等有效帧采集完成。
2. 保持提离和板边方向固定，分别停在阵列外近点、入口和阵列内几个实测位置。输入板边推进距离并采集模板。以进入侧网格外边界为 0，推进一个线圈间距为 1，阵列外用负值。
3. 采集至少两个不同板位后，窗口可按当前位置模板估计板边和 4×4 格子覆盖率。使用同板型、同提离的一次独立扫描复测。覆盖率由横跨阵列的平行直板边计算。设置匹配残差上限前，结果用于试算。
4. 在覆盖分析窗口点击 **加载标定**。设备、通道布局和测量条件匹配后，主界面切到 **覆盖率（%）**。把钢板完全移远，点击 **重采当前空场（保留模板）**。采完后按原方向移动钢板。空场重采用于本次连接，位置模板继续可用。
5. 用主界面的「显示」菜单选择 **原始衰减（mV）**、**覆盖率（%）** 或 **公共补偿（mV）**。公共补偿用至少 4 个未覆盖参考格的衰减中位数估算公共变化，再根据各通道在未覆盖标定点的响应比例扣除。标定样本不足的通道按等比例扣除。残差超限时先重采当前空场，若特定板位仍超限，可在该位置补采模板。

## 4. 串口连接

1. STM32 通过 USB 接入 Windows，会出现新的 COM 端口。
2. 打开软件 → 在顶部"连接"区**从枚举列表中选择** COM 口
   （程序不硬编码任何端口号）。
3. 波特率显示 115200（USB CDC 配置显示，与实际速率无关）。
4. 点击"连接"。
5. 收到第一帧合法 D 帧后，状态从"协议不匹配/等待数据"变为
   **"接收中"**，热力图与曲线开始刷新。

> **上位机不发送任何命令到串口**（v3 固件无命令接口）。

## 5. 16 通道

- D 帧每帧发送全部 16 通道的 mV 值。
- 上位机**默认启用全部 16 通道**；可在"设置 → 激活通道"中裁剪。
- 热力图永远显示 4×4 = 16 格；未启用格子为灰色"未启用"。
- `valid_mask=0` 的通道显示"本帧无效"，不参与滤波/基线/统计。
- 掩码为 1 的 `0.000` 是**有效读数**（不是"无数据"）。

### 5.1 通道布局（换板必读）

布局只决定 **CH01–CH16 在 4×4 热力图中的位置**，不改变任何数据：
`samples_mv[i]`、`valid_mask` bit i、启用通道、CSV 列顺序永远按通道号。

入口：**设置 → 通道 → 布局**

| 布局 | 说明 |
|---|---|
| 旧面包板（4 列，每列自下而上） | 原有布局，保持不变 |
| 有源线圈 PCB（元件面朝观察者，FPC 朝左） | 自上而下：CH09-12 / CH13-16 / CH08-05 / CH04-01 |

主界面顶部会显示 `Profile: … \| 布局: …`。换布局后会**清空上一块板的
滤波/曲线/故障状态**，并按新布局重新判定基线是否适用。

### 5.2 线圈绑定（有源板必读）

存在**两张互相冲突**的「线圈标签 ↔ 串口电压序号」表，必须由用户
**逐点实测确认后显式选择并存盘**（入口：设置 → 通道 → 线圈绑定 +
勾选"已逐点实测确认"）：

| 绑定 | CH01 | CH02 | … | CH08 | CH09 | … | CH16 |
|---|---:|---:|---:|---:|---:|---:|---:|
| **PCB 设计对应**（默认） | 1 | 2 | … | 8 | 9 | … | 16 |
| **v3.4.1 旧映射** | 9 | 10 | … | 16 | 8 | … | 1 |

- 选中"有源线圈 PCB"布局时**默认使用 PCB 设计对应**，绝不静默套用旧表；
  旧配置里的映射会被识别为对应绑定并保留，同时标记"需实测确认"。
- 未勾选"已逐点实测确认"时，主界面标题会显示"（绑定未实测确认）"。
- 详情面板同时给出：线圈标签、帧号、串口电压序号（mV 之后第 n 个）、
  ADC 原始 mV、valid_mask 有效位；滤波值与分压补偿后的 VOUT 分开展示。
- 回放严格按 CSV 里记录的映射还原坐标、标签、详情与图例；退出回放
  恢复实时布局。
- 串口帧、采集数组、滤波、基线、CSV 列（`ch01…ch16`）**始终按固件
  原始顺序**，绑定只在"数据绑定到格子"时应用一次。

**物理格子 → ADG706 地址 → 串口电压序号**（设计对应绑定；旧映射按上表换算）

| 物理位置 | 标签 | ADG706 地址 | 串口电压序号（mV 后第 n 个） | CSV 列 |
|---|---|---|---:|---|
| 第 1 行左 | CH09 | 0x8 | 9 | ch09 |
| 第 1 行右 | CH12 | 0xB | 12 | ch12 |
| 第 4 行左（左下） | CH04 | 0x3 | 4 | ch04 |
| 第 4 行右（右下） | CH01 | 0x0 | 1 | ch01 |

（ADG706 地址 = 串口电压序号 − 1；固件按地址递增顺序发包。）

## 6. 单位与 ADC Profile

- 测量单位：**mV**。D 帧值即 ADS1115 AIN0 电压（Vadc）。
- VOUT 估算 = Vadc × 分压比（默认 Profile 为 ×2，反推 AD8362 输出）。
- 显示精度：采样/滤波/基线/Δ/VOUT 均 **3 位小数**（如 424.625 mV）。
- 默认 Profile = `ads1115_4v096_div2`（±4.096V PGA + 1:2 分压）。
- 有源线圈 PCB 若检波输出**直连** ADS1115（无 1:2 分压），请选择
  `ads1115_4v096_direct`（分压比 1.0）；**Profile 与布局是两个独立设置**，
  换布局不会改变分压补偿，改 Profile 也不会改变显示位置。
- 分压补偿只乘一次：`VOUT = D 帧值 × 分压比`，采样值本身保持 ADC mV。
- 饱和判定：mV 量程边界（≤ -4096.000 或 ≥ 4095.875）。

## 7. 无钢板基线标定（实验流程核心）

实验流程：**先无钢板标定基线 → 再放入钢板观察信号衰减**。

1. 移除钢板，保持线圈位置、激励频率和增益不变，待信号稳定。
2. 点击"开始无钢板基线标定"，按提示确认现场无钢板后开始。
3. 前 2 帧仅作滤波预热不计数；之后每个**不同的 D 帧**对每个
   有效通道计 1 个样本（同帧去重，不用 UI 刷新次数冒充采样次数）。
4. 无效 / 非有限 / 饱和 / 非当前会话的样本一律剔除；持续有帧但某
   通道始终无有效样本会提前失败并列出通道。
5. 基线 = 滤波值**中位数**；质量报告在**原始有效样本**域观察噪声
   （std/MAD）、漂移与异常点。`MAD/|median| > 0.05`（无量纲，软件
   自检门限，不是硬件合格标准）判为不稳定并拒绝。
6. 全部通道达标后**原子提交**；取消 / 失败 / 断连一律保留旧基线。
7. 成功后提示"无钢板基线已建立，请放入钢板测量"；基线固定，
   不做自动追踪。

基线按**来源 + 设备 + 布局 + 测量条件**分库保存（`config.json`）：
- 来源：`serial`（串口）/ `tcp`（网络）/ `demo`（演示，绝不覆盖硬件）
- 设备：串口用 USB VID:PID+序列号，TCP 用人工填写的采集设备编号
- 布局：旧面包板 / 有源线圈 PCB **各自独立**，换板后旧基线不会套用
- 测量条件：ADC Profile、频率、增益、线圈；任一项变化后旧基线不再
  自动应用，界面会提示原因并要求重新标定
- 每套基线附 meta：来源、设备标识、布局、单位、通道、时间、
  ADC/检波配置、频率、增益、baseline_id、衰减公式版本
- **旧配置只有一个基线槽**：加载时自动迁移进历史库（保留可识别的
  旧基线），之后再标定新板不会覆盖它
- 旧配置的无来源扁平基线：加载时**备份并标记"待确认/需重新
  标定"**，绝不静默沿用

## 8. 热力图含义

- 默认 4×4 = 16 格（行 0..3，列 0..3）。
- 每格颜色编码 **衰减量 = 无钢板基线 − 当前检波电压（滤波，mV）**：
  - **正值：信号下降**（放入钢板的预期方向）；**负值：信号升高**
    （如实显示，不取绝对值）；零点附近为中性色。
- 未标定 / 本帧无效 / 饱和 / 断流：显示状态文本与状态底色，
  **绝不显示成正常零值**。
- 色阶对称（±X mV，图例带 mV 标记）：可固定色阶做标定前后对比，
  也可自动色阶（仅观察相对变化）。
- 颜色只表示测量响应，不代表厚度/距离/缺陷等物理结论。
- 单元格 tooltip：衰减量/下降比例/基线/滤波/采样/VOUT/本帧有效性。

## 9. CSV 记录（schema v4）

- 顶部"实验记录"区；默认目录 `%USERPROFILE%\Documents\涡流传感器采集系统\data\`。
- UTF-8 BOM，Excel 可直接打开；独占创建，永不覆盖。
- **schema_version = 4**，含 `measurement_unit = mV` 列。
- 全部测量列 3 位小数；16 通道统一列（未启用也保留）。
- **每行 wire mV 直接来自当前 D 帧**；`valid_mask=0` 通道写空值。
- 列结构：
  - 全局：`schema_version, app_version, 相对时间/s, 时间戳, 帧号,
    状态, valid_mask, i2c_err, source, session_id, measurement_unit`
  - 每通道：`chXX_wire_mv, chXX_raw_valid, chXX_filtered_mv,
    chXX_baseline_mv, chXX_delta_mv, chXX_delta_signed_mv,
    chXX_percent_signed, chXX_attenuation_mv,
    chXX_detector_drop_pct, chXX_status`
  - 尾部：`attenuation_formula, baseline_source, baseline_id,
    baseline_device_id, ADC_Profile, vref_mv, invert_sign,
    enabled_channels, channel_map, 实验备注, 激励频率, 频率单位,
    增益, 线圈, 铁板`
- 新列（v4 新增，旧列语义一律不变）：
  - `chXX_attenuation_mv = baseline − filtered`：相对无钢板基线的
    衰减量，正=信号下降，负=信号升高（如实写负值）。
  - `chXX_detector_drop_pct`：检波电压下降比例（%），仅在基线为
    正且 ≥ 1.0 mV 有效下限时写出，否则留空（未知 ≠ 0）。
  - 当前帧无效/饱和/断流时，**派生列（衰减量/百分比/旧Δ）全部
    留空**，不使用上一帧残留值。
  - `attenuation_formula`：公式版本标识（
    `attenuation_mv=baseline_mv-filtered_mv@v1`）。
- 旧 `chXX_delta_mv` 保持旧语义（filtered − baseline，诊断量）；
  `chXX_delta_signed_mv` 应用 invert_sign（invert 只影响旧诊断量，
  绝不再翻转衰减量）。
- 每帧 flush + fsync；写失败自动停止并弹窗报错。
- **录制期间锁定设置**：一个 CSV 必须整份实验条件一致，因此录制中
  不允许修改通道布局、ADC Profile、激励频率/增益/线圈等设置；
  需要修改时请先"停止记录"，程序会明确提示。
- 旧文件若在录制中被改过布局（同一列 `channel_map` 出现多种取值），
  回放时会提示"布局冲突"，按首行布局显示，数据列仍按 CH01–CH16。

## 10. CSV 回放

- 支持 **schema v3 与 v4** 文件：播放/暂停/停止/进度条/0.5×~4× 倍速。
- v3 文件：无衰减列 → 衰减量/百分比显示"—"（未知，不默认为 0）。
- v4 文件：**直接回放保存的衰减值**，不重算、不做符号翻转；
  空单元格 → "—"。
- 回放基线只用于显示历史数据，**不会保存成当前硬件基线**；
  退出回放后恢复当前来源作用域的基线。
- **VOUT 按记录时的 `ADC_Profile` 计算**：旧 1:2 分压文件里 ADC
  1000 mV 回放为 VOUT 2000 mV，即使当前实时配置是"无分压"；
  记录缺失/Profile 不可识别时 VOUT 显示"—"（未知），ADC mV 与
  已保存的衰减量/百分比仍按记录值显示。退出回放恢复实时分压配置。
- **schema v2（旧 raw count 文件）明确拒绝**，提示单位不兼容、
  请用 v3 上位机重新记录。

## 11. 演示模式

- 不依赖硬件，模拟完整实验流程：`sample = 空气基线 − 钢板响应
  + 漂移 + 噪声`。
- 默认【无钢板】状态：可先演示真实的标定操作顺序；
  点击"放入钢板"后电压下降、衰减量增大；"移除钢板"后回到基线
  附近（不强制归零）。
- 输出与串口路径同语义：mV、0.125 步进、量程 ±4096，
  静态工作点约 1500 mV（量化/限幅仅作用于模拟数据）。
- 界面始终标注"模拟数据"，不模拟串口连接成功。
- 与真实串口共用同一套 ChannelProcessor → 热力图/曲线/CSV 链路。
- 启动：`python main.py --demo`，或 GUI 内点击"演示模式"。
- 也可用 `serial_simulator.py` 向虚拟串口写 v3 帧调试。

## 12. 常见故障

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 状态显示"无数据" | 串口未打开 / USB 拔出 / 设备没上电 | 检查连接、确认 D+ 拉升 |
| 状态显示"协议不匹配" | 收到字节但无合法 D 帧 | 确认固件为 v3（D 帧 22 字段带 mV 标记） |
| 状态显示"数据陈旧" | 曾有 D 帧但 5s 内无新帧 | 检查 USB 总线、固件是否卡死 |
| 状态显示"设备故障 (INIT=...)" | E 帧 init_status != 0 | 检查 ADS1115 接线、重新上电 |
| 启动提示"基线缺少来源信息/待确认" | 旧配置基线已备份作废 | 移除钢板后重新做无钢板基线标定 |
| 热力图一直是"未标定" | 未做无钢板基线标定 | 点击"开始无钢板基线标定" |
| 标定失败"始终无有效样本" | 该通道无效/饱和/超量程 | 检查线圈与接线、确认未贴钢板 |
| 标定失败"基线不稳定" | 标定中目标移动/条件变化 | 保持无钢板状态稳定后重试 |
| 修改激励频率/增益后数值突变 | 实验条件变化使基线失效 | 移除钢板后重新标定 |
| 串口打不开 | 端口被占用 / 驱动问题 | 在设备管理器中查看 |

## 15. v3 迁移摘要

- **数据模型**：`DFrame.samples_mv`（16 元组 float mV）为权威；
  解析经整数 µV 验证（范围 + 125 µV 步进）后转 float，
  0.125 倍数二进制精确无累计误差。
- **解析器**：严格 22 字段；parts[5] 必须为 `mV`；正则
  `^-?\d{1,4}\.\d{3}$`；范围/步进校验；错误不崩串口线程。
- **处理链**：中值/EMA/基线/Δ 全 mV；无 raw_to_vadc 二次换算；
  饱和 = mV 量程边界。
- **测量语义**：统一快照 `core/measurement.py`（详情/热力图/
  tooltip/曲线/CSV 同源）；衰减量 = 无钢板基线 − 滤波值，
  检波电压下降比例仅在基线为正且 ≥ 1.0 mV 时给出。
- **配置**：CONFIG_VERSION=4，基线按 serial/demo 作用域隔离并
  记录设备标识与实验条件；旧无来源基线备份作废并提示重新标定。
- **CSV**：schema v4 + 衰减量/下降比例列 + 公式版本与基线来源列；
  回放支持 v3/v4，v3 衰减量显示未知，v2 明确拒绝。
- **UI**：主显示为衰减量与检波电压下降比例；采样/滤波/基线/VOUT
  为次级详情（全 mV 3 位小数）；曲线可切换电压/衰减量视图。
